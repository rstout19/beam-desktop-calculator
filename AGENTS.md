# Project instructions

This project is a Python desktop application built with Tkinter, NumPy, and Matplotlib. Start it with `python app.py`.

- Keep application interfaces and workflows native to the desktop app. Do not add web app requirements such as browser layouts, HTML, CSS, JavaScript, or web deployment.
- Use Tkinter for the desktop interface, NumPy for numerical work, and Matplotlib for plots where appropriate.
- After each request, add an entry to `spec.md/prompts.md`: what I asked, what you changed, and whether it worked.
